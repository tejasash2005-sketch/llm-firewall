# Security reporting

Please do not report an exploitable vulnerability in a public issue. Use GitHub's private
vulnerability reporting feature for this repository if it is enabled. If private reporting is
not enabled, contact the repository maintainers using a verified contact listed in the GitHub
organization or repository profile and include no exploit details in a public issue.

Before publishing this repository, maintainers should enable private vulnerability reporting or
add a monitored security contact here. No response-time commitment is currently stated.

Include the affected version or commit, relevant configuration, impact, and a minimal
reproduction. Avoid sending real provider credentials, personal information, or production
traffic in a report. Please allow maintainers time to investigate and prepare a fix before
public disclosure.
